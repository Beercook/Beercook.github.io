性能优化建议

  1. 启用缓存：使用 CDN 加速静态资源
  2. 图片优化：压缩图片，使用 WebP 格式
  3. 减少插件：只安装必要的插件
  4. 内存限制：在 PM2 中设置 max_memory_restart

A:

  3. 运行 npm install
